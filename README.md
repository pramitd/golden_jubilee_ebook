# Golden Jubilee ’76

Commemorative ebook for the NIT Raipur class of 1976.

The live site is a Vite app. Profile text is `public/public_data.json`. Photographs are in `public/assets/profiles/`. The downloadable album is `public/golden-jubilee-high-resolution.pdf`.

```bash
npm install
npm run dev
```

```bash
npm run build
```
