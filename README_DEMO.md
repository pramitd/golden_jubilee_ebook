# Golden Jubilee — Form → JSON → React → GitHub → Vercel Demo

This is the **V4 presentation layer** with the current four test participants already loaded.
The Google Form, Apps Script ingestion, REVIEW sheet, Dashboard and `generatePublicJSON()` remain unchanged.

## Current flow

Google Form → Apps Script ingestion → REVIEW / approval → `generatePublicJSON()` → `public_data.json` → React/Vite → GitHub → Vercel

## 1. Current 4-entry demo

The checked-in `public_data.json` is the current four-participant snapshot generated by the existing Apps Script pipeline.

## 2. Sync the latest generated JSON

After the coordinator runs `generatePublicJSON()` again, copy the new Google Drive JSON file ID into `PUBLIC_JSON_FILE_ID` if it changed.

PowerShell:

```powershell
$env:PUBLIC_JSON_FILE_ID="YOUR_NEW_JSON_FILE_ID"
npm run sync:data
npm run dev
```

If the Drive JSON is link-accessible, the script downloads it automatically. If not, the checked-in snapshot is retained.

## 3. Local production test

```powershell
npm install
npm run build
npm run preview
```

## 4. GitHub

From the project directory:

```powershell
git init
git add .
git commit -m "Golden Jubilee ebook demo"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/golden-jubilee-ebook.git
git push -u origin main
```

Create the GitHub repository first; do not initialize it with another README.

## 5. Vercel

Import the GitHub repository into Vercel.

Settings:

- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

Add the Vercel Environment Variable:

`PUBLIC_JSON_FILE_ID = <current generated public JSON file ID>`

Then Deploy.

## Important: photos

The JSON contains Google Drive file IDs. The browser can only display the photos if the image source is accessible to the browser. For this first demo, the safest approach is to make a **separate demo asset set** containing only the four test participants' approved photos, rather than exposing the entire response Drive.

Do not change the production sharing permissions of the response folders merely to make the demo work.
